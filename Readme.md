# DEPENDANCES: 

## Outils de compilation

```shell
sudo apt update
sudo apt install -y \
    build-essential \
    cmake \
    ninja-build \
    pkg-config \
    git
```

## Qt6 et modules de compilations:

```shell
sudo apt install -y \
    qt6-base-dev \
    qt6-base-dev-tools \
    qt6-httpserver-dev \
    libqt6sql6-psql
```
